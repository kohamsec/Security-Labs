# Security-Labs
Open-source Linux, Windows &amp; Active Directory security labs, built to learn and shared so you can too.

A growing collection of home labs covering Linux, Windows, and Active Directory,
built for learning offensive security in a safe, legal environment.

## What's inside
- **Linux labs**: misconfigurations, privilege escalation, and hardening
- **Windows labs**: enumeration, local privilege escalation, and defenses
- **Active Directory labs**: multi-domain setups, attack paths, and detection notes

Each lab includes build instructions, walkthroughs, and lessons learned.

## Disclaimer
All content is for educational purposes and authorized testing only. Only use
these techniques in environments you own or have explicit permission to test.
